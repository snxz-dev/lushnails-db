# Delegación de Comandos de Terminal

1. **No ejecutar comandos directamente**: No utilizar la herramienta de ejecución de terminal para comandos de shell/sistema salvo que el usuario lo solicite expresamente con "ejecútalo tú".
2. **Proporcionar comandos claros**: En su lugar, presentar los comandos en un bloque de código markdown listo para copiar, indicando el directorio de trabajo donde deben ejecutarse.
3. **Foco en el aprendizaje**: Explicar brevemente qué hace cada comando o bandera importante para que el usuario conozca lo que está sucediendo en su sistema Arch Linux.
